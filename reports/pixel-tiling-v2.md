## Automatable checks
1. Token-colour sampler: for each capture, take the histogram of flat fills in the chrome regions (bar, overlays, helper surfaces) and flag any flat colour not within dE 3 of the palette table in tiling-v2.md (finds #1, #2, #4, #5, #14, #15, #17, #19). Needs the table as JSON, both themes.
2. Corner-radius probe: at known rects (tile, island, panel, selected row), sample the 12x12 corner and compute the radius from the first opaque pixel per row; fail if the radius is not 10/12/14 or is 0 (finds #1, #2, #11).
3. Fullscreen interior check: with a fullscreen window, sample the island bboxes; fail if any pixel differs from the island fill by more than tolerance, or if a bar exists at all (finds #3).
4. Overlap detector: from the layout tree (choractl list), check helper surfaces' rects against bar rects, tile rects and border bands; fail on any intersection other than designed ones (finds #4, #13, #14).
5. Geometry assertion: overlay size and anchor against the spec (880x560, centred, grid-multiple of 4) (finds #6).
6. Column alignment checker: from the layout dump, cap x-start, cap x-end and label x per column are constant, caps pad equal (finds #8).
7. Island padding and icon bbox: first/last content pixel to island edge in 12..16, icon bbox 16 x 16, icon colour equals its label colour (finds #9, #10).
8. Desktop-entry lint on the launcher list: no NoDisplay, no duplicate names, no parenthesised build info (finds #12).
9. Stray saturated-pixel detector: any pure (255,255,0) or similar probe colour in a published capture fails (finds #13); run in the capture script.
10. OCR text-height check: every OCR box under 14 px (1x) outside terminal content fails (finds #14).
11. Edge-profile test: luminance across a focused tile edge must show border width 2 px and a shadow falloff of at least N levels; same at 2x (finds #18, regressions of the verified 12/10 gaps).
12. Capture matrix: scale 1, 1.25, 1.5, 2 for desktop, keys, power, apps; half-pixel check = no edge row with two partial-alpha rows for tile borders (finds #20).
