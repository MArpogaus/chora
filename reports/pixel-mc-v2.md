## Automatable checks (add to the capture gate)

1. Accent/focus bar height != cap height of its text: for each 1-2 px wide rect adjacent (<30 px) to a text run, require top == cap top and bottom == baseline within 1 px (catches B1, B3, B4).
2. Bar centred between neighbours: gap left == gap right +-2 (B2).
3. Rule vs text overlap: no hairline rect intersects a text bbox; no text bbox beyond H-28 or the column (finding 1).
4. Baseline equality for runs on one row, and last-row baseline == footer baseline (10, 16).
5. Line pitch of each text block == 28 (6); gap between list items >= 14 (7).
6. Right/left ink edges per column equal +-1 incl. trailing letter-spacing (9).
7. Min rendered text height >= 14 px, incl. embedded terminal; scan stderr for config errors (2).
8. Box count: only the question card may have a full border (4); font-family allowlist (Pagella, Inter, mono).
9. 1x vs 2x: downsample the 2x capture and diff with the 1x capture; flag regions with edge-sharpness below a threshold (soft field text).
10. Section-structure check against the doc order (heads, time-left, Enter hint) (5, 12).
