That holds for glibc (SIGRTMIN=34), but musl has SIGRTMIN=35, so on musl the trap ignores SIGRTMIN and leaves RTMIN+1 default. chora-tiling sends by name (`kill -s RTMIN+1`). dash cannot trap `RTMIN+1` by name, so a bash or `kill -l` lookup would be needed. 3. MINOR waybar.sh:81-85: a small race stays. waybar.pid is written by the parent right after the fork, before the subshell has run its trap. A signal that lands in that window kills the subshell. It is far narrower than the old race. Setting the trap in the parent before the fork (and resetting it in the parent after) would close it.
