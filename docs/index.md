# Void

A policy-free, programmable Wayland compositor: a canvas, not a desktop.

Void ships no window manager, no layout, no keybindings, no look. It provides
a small scene of primitives, a render loop, Wayland protocol handling and one
API. Everything else is a plugin.

!!! note "Working document"
    Void is in its concept phase. These pages collect the ideas and decisions
    so far; they will grow into the official documentation. Every decision is
    up for a critical review — see [Decisions and open questions](decisions.md).
