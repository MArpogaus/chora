# Gate of plan 0.8 (run 2026-10-24, commit dd941b0)

Each gate check of roadmap section 0.8 has one script,
`tests/gate-0.8-<n>.sh`. A script answers `ok:` or `SKIP: <why>` with
exit 0, and `FAIL: <why>` with exit 1. They are idempotent: each starts
its own headless session and cleans it up. Run all of them with:

```bash
for n in $(seq 11); do tests/gate-0.8-$n.sh || echo "gate $n failed"; done
```

Checks 1, 2, 6 and 10 need the binaries in `target/debug` (`BIN`
overrides). Checks 5 and 8 run single unit tests through
`micromamba run -n chora cargo test`. Checks 4 and 11 need sway, foot
and grim, which this sandbox does not have.

| 2 node click under pan and zoom, 20 of 20 | ok | camera at translate [-140, -60] and scale 1.5; all 20 `pointer_move` clicks in node coordinates press the node |
